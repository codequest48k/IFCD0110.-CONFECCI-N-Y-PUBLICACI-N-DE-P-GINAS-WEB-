# 🧩 Instalación y utilidad de extensiones en Visual Studio Code

## 📘 Introducción

Visual Studio Code (VS Code) es un editor de código potente, ligero y personalizable.  
Una de sus mayores ventajas es la posibilidad de instalar **extensiones**, que amplían sus funciones y mejoran la productividad.  

A continuación se explican cuatro extensiones recomendadas para trabajar con desarrollo web:

- **Live Preview**  
- **Image Preview**  
- **Auto Close Tag**  
- **2077 Theme**

---

## 🔹 1. Live Preview

### 📦 Descripción  
Permite visualizar en tiempo real cómo se ve el código HTML directamente en el navegador o dentro del propio VS Code.  
Cada vez que se guarda un cambio, la vista se actualiza automáticamente.

### 💡 Utilidad  
- Ideal para probar proyectos web de forma rápida.  
- Facilita el diseño y la depuración visual.  
- Ahorra tiempo al evitar recargar manualmente el navegador.

### ⚙️ Instalación  
1. Abrir **Visual Studio Code**.  
2. Ir al icono de **Extensiones** o pulsar `Ctrl + Shift + X`.  
3. Buscar `Live Preview`.  
4. Seleccionar la extensión oficial de **Microsoft** y pulsar **Install**.  
5. Una vez instalada, ejecuta con el comando **“Live Preview: Start Server”** o el botón “Go Live”.

---

## 🔹 2. Image Preview

### 📦 Descripción  
Muestra una vista previa de las imágenes dentro del editor al pasar el cursor sobre una ruta o nombre de archivo (`.jpg`, `.png`, `.gif`, etc.).

### 💡 Utilidad  
- Permite comprobar rápidamente que las imágenes se cargan correctamente.  
- Evita abrir archivos externos solo para verificar su contenido.  
- Muy útil para proyectos con muchas referencias visuales.

### ⚙️ Instalación  
1. Abrir el panel de extensiones (`Ctrl + Shift + X`).  
2. Buscar `Image Preview`.  
3. Seleccionar la extensión de **Kisstkondoros**.  
4. Pulsar **Install**.  
5. La vista previa aparecerá automáticamente al pasar el ratón sobre las rutas de imagen.

---

## 🔹 3. Auto Close Tag

### 📦 Descripción  
Agrega automáticamente la etiqueta de cierre (`</...>`) al escribir una etiqueta HTML o XML.

### 💡 Utilidad  
- Evita errores de sintaxis en HTML.  
- Ahorra tiempo escribiendo código.  
- Mejora la legibilidad y consistencia del código.

### ⚙️ Instalación  
1. Buscar `Auto Close Tag` en el panel de extensiones.  
2. Seleccionar la extensión creada por **Jun Han**.  
3. Pulsar **Install**.  
4. Se activa automáticamente al escribir etiquetas HTML o JSX.

---

## 🔹 4. 2077 Theme

### 📦 Descripción  
Tema visual inspirado en el videojuego *Cyberpunk 2077*.  
Cambia los colores del editor con un estilo futurista y oscuro.

### 💡 Utilidad  
- Mejora la experiencia visual del usuario.  
- Reduce la fatiga ocular durante largas sesiones.  
- Permite personalizar el entorno de trabajo.

### ⚙️ Instalación  
1. Buscar `2077 Theme` en el panel de extensiones.  
2. Instalar la extensión de **Endormi**.  
3. Activar desde:  
   - Menú: **File > Preferences > Color Theme**, o  
   - Atajo: `Ctrl + K`, luego `Ctrl + T`.  
4. Seleccionar **2077 Theme**.

---

## ✅ Conclusión

Estas extensiones mejoran la **eficiencia**, **productividad** y **comodidad** al trabajar con código.  
Combinan herramientas útiles para desarrollo web (Live Preview, Image Preview, Auto Close Tag) con una experiencia visual atractiva (2077 Theme).

💻 Con ellas, Visual Studio Code se convierte en un entorno moderno, práctico y agradable para programar.
